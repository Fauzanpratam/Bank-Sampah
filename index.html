Hubungkan Google Sheets

Satu kali setup — data tersimpan permanen di Google Sheets Anda

📋 Langkah Setup:
  1. Buka Google Drive → buat Google Sheet baru di folder Anda
  2. Di Sheet → klik Extensions → Apps Script
  3. Hapus kode lama, paste kode dari file Code.gs yang terlampir → Save
  4. Klik Deploy → New deployment → tipe: Web app
  5. Execute as: Me  |  Who has access: Anyone → Deploy
  6. Copy Web app URL yang muncul → paste di bawah ini
URL tidak valid. Harus dimulai dengan https://script.google.com
